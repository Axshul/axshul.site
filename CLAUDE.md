# CLAUDE.md - axshul.site

## Project Overview

Personal portfolio and content hub for Anshul Namdev (axshul.site). A static, multi-page website with no build system or framework: pure HTML, CSS and vanilla JavaScript. Hosted through AquaHost (LiteSpeed, 148.113.8.71) at `https://axshul.site`. The GitHub repo is the source of truth only: it has **no GitHub Pages deployment**, so a push never changes the live site. The user handles AquaHost deployment. Push validated source to GitHub and provide the release zip under `_uploads/`; do not deploy hosting unless separately requested.

**Repository:** `https://github.com/Axshul/axshul.site.git`

## Hard rules

- Make all changes directly on `main`. Do not create feature branches for this repository.
- Preserve existing public page URLs, canonicals, article anchors and published media URLs. The homepage must retain `#hero`, `#community` and `#journey` compatibility targets.
- **No em-dashes anywhere** on the site (HTML, JS, JSON, XML). Use a comma, a colon, or " - ". En-dashes for ranges are fine.
- Brand colours stay: black / white, red `#D72638`. The approved site uses ink `#111210` and off-white `#FAFBF8` across every public route. Red is a rare signal, never a fill for whole sections.
- Every public page uses the shared white capsule header (`Work · Guides · About · Blog`) and a "Let's talk" link. The homepage also has Photos and section anchors. Inner routes use page links and a footer site index. Keep the wordmark text and native navigation visible without JavaScript.
- Nothing unnecessary goes live: no unreferenced assets, prototypes or template pages in the repo root.
- Legal pages (`/privacy/`, `/cookies/`, `/terms/`, generated by the builder) must stay truthful: any new form, storage, embed, analytics or third-party request has to be added to them and the date bumped before it ships. Every page links to all three (footer row on portfolio pages, `footer-links` on guide/thoughts pages, the fixed `#site-legal` badge on the tool apps).

## Architecture

### Stack
- **HTML5**, one `index.html` per route directory
- **CSS3**: `assets/css/landing.css` + `landing-motion.css` + `landing-gallery.css` + `landing-scroll.css` (white homepage), `assets/css/hive.css` (about, work, experience, contact, blog, n8n hub), `assets/css/n8n.css` (guide articles + `/thoughts/`)
- **Vanilla JS**: `assets/js/landing.js` + `landing-gallery.js` + `landing-scroll.js` (homepage enhancement, scroll choreography and photo viewer), `assets/js/site.js` (shared header, inner reveals and contact handler), `text-highlight-share.js` (guide articles). Legacy `hive.js` and `3d-anim.js` are no longer loaded by public pages
- **Fonts:** homepage Barlow Condensed, Space Grotesk and IBM Plex Mono are local Latin WOFF2 files in `assets/fonts/landing/`, with SIL OFL licenses. All default page and tool fonts are self-hosted. Notes requests Google Fonts only for explicitly selected optional fonts.
- **External deps:** Three.js (functional Galaxy canvas), Fabric.js and other tool libraries, Calendly (contact page), Hacker News API (blog). Decorative Three.js was removed from articles. The homepage loads no third-party assets.

### No build step
Serve the folder with any static server (`python3 -m http.server`), or open files directly. No `package.json`.

## Homepage (`assets/css/landing.css`, `landing-motion.css`, `assets/js/landing.js`)

White rounded hero stage, oversized two-line name, real event photo and folded hexagonal leaderboard seal. Homepage sections: About (community evidence in native details), From the room (7 selected event photos), Selected work, n8n guides and mail contact. Do not add Nexus or Neural Notes to homepage material. Keep content in HTML and the full name readable at every breakpoint.

CSS provides a brief entrance, layered hex geometry and wire draw. Scroll choreography progressively fills the outlined surname, moves the two name rows in opposite directions, and traces section transitions. A slim reading line follows page progress. JS adds one-time reveals only to below-fold content, marks the active section and applies bounded pointer depth on desktop. Ambient motion pauses offscreen and while the document is hidden. Reduced-motion preferences skip motion; focused content and hash targets reveal immediately. No loader, scroll hijacking, cursor replacement, storage or API calls.

The curated photo sheet uses one portrait anchor, sticky copy, paper-frame entrances and bounded opposing card drift on desktop, then a normal responsive grid on phones. Seven selected event photos are actual lazy-loaded `img` elements with responsive small/large exports and accurate scene descriptions. Each links to its larger original. A native dialog adds keyboard navigation, Escape/close and focus return, with native links as the no-JS fallback. The hero photo opens its matching gallery frame. Person/ProfilePage/image metadata and the homepage image sitemap use those existing stable URLs. Do not turn event props into claims that Anshul won an award or held an ambassador role.

Focus reveals only the card containing the focused element. Hash navigation can reveal the target's descendants. Initial focus is often `BODY`, which must not clear every pending photo entrance.

## Legacy structural styles (`assets/css/hive.css`)

Portfolio layouts retain their structural classes. `landing.css`, `landing-motion.css`, and `site.css` load afterwards to apply the approved white theme. Public pages do not load the old loader, canvas, cursor or `hive.js`. The following tokens document the historical design only.

Black / grey honeycomb with a single red signal.

```css
--line: rgba(255,255,255,.07);  --line-2: rgba(255,255,255,.14);
--text: #f3f3f1;  --soft: #cfcfcb;  --muted: #8d8d8a;  --dim: #5a5a58;
--red: #D72638;  --red-dk: #B71C2C;
--font-display: 'Playfair Display'  (headings, italic for emphasis)
--font-body: 'Space Grotesk'         (copy, weight 300)
--font-mono: 'Space Mono'            (labels, nav, tags, uppercase + tracking)
--hex: polygon(50% 0,100% 25%,100% 75%,50% 100%,0 75%,0 25%)
```

Building blocks: `.wrap` (1240px), `.sec` + `.sec-head` (index / line / name), `.sec-title`, `.btn` / `.btn-primary`, `.tag`, `.soc` (hexagon icon button), `.cell` honeycomb cells, `.tl` timeline with hex nodes, `.form` / `.field`, `.foot` with outlined wordmark.

### Historical motion (no longer loaded by public pages)
- `#hive canvas`: fixed honeycomb lattice drawn in world space (parallax 0.18). Cells brighten near the pointer, a wave passes through the lattice while scrolling, a few red cells breathe. Static single draw under `prefers-reduced-motion`.
- Reveals are **scroll-driven** (`.rv` gets `.in` when its top passes 92% of the viewport; `.rv-l/.rv-r/.rv-s` variants; `.rl > span` line masks; `.rv-0` = trigger only). No IntersectionObserver.
- Hero entrance is pure CSS (`.h-in`, `.h-rl`), so it never depends on JS. `html.fast` (set from `sessionStorage`) skips the loader on repeat visits.
- Cursor (fine pointers only), magnetic `.btn`, portrait tilt, nav `.scrolled`, progress bar, hero/footer wordmark drift, timeline fill.
- Gotcha: keep `overflow-x: hidden` on `html`, never on `body` (body becomes the scroller and `window.scrollY` stays 0).

## Development Notes

- Preview: `python3 -m http.server 8890` from the repo root (the desktop app's launch config serves the same folder on 8888).
- Release: `_uploads/axshul.site-release.zip` (repo minus dev files) and `_uploads/DELETE-ON-HOST.txt` (paths removed since the last deploy).
- When adding a portfolio page: copy an existing white page's header/footer, load structural `hive.css` before `landing.css`, `landing-motion.css`, `site.css`, and defer `site.js`. Add metadata and the route to `sitemap.xml`. Tools also use `apps-white.css` and retain their functional JavaScript.
- When adding a guide article: create `/n8n/guide/<slug>/index.html`, add it to the guide index and to `sitemap.xml`.
- Commit style: short imperative subject (e.g. `Fix hero image CDN 404`, `+ Article + sitemap updated`).
