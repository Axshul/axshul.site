# CLAUDE.md - axshul.site

## Project Overview

Personal portfolio and content hub for Anshul Namdev (axshul.site). A static, multi-page website with no build system or framework: pure HTML, CSS and vanilla JavaScript. Hosted on GitHub Pages at `https://axshul.site` (deploys from `main`).

**Repository:** `https://github.com/Axshul/axshul.site.git`

## Hard rules

- **No em-dashes anywhere** on the site (HTML, JS, JSON, XML). Use a comma, a colon, or " - ". En-dashes for ranges are fine.
- Brand colours stay: black `#050505` / white, red `#D72638`. Red is a rare signal, never a fill for whole sections.
- The navbar must be identical on every page that has it: `01 About · 02 Work · 03 Journey · 04 N8N · 05 Blog` plus a single "Let's Talk" CTA to `/contact/`. No duplicate Contact link.
- Nothing unnecessary goes live: no unreferenced assets, prototypes or template pages in the repo root.

## Architecture

### Stack
- **HTML5**, one `index.html` per route directory
- **CSS3**: `assets/css/hive.css` (HIVE design system: homepage, about, work, experience, contact, blog, n8n hub), `assets/css/n8n.css` (guide articles + `/thoughts/`)
- **Vanilla JS**: `assets/js/hive.js` (site engine, every HIVE page), `assets/js/3d-anim.js` + `text-highlight-share.js` (guide articles)
- **External deps:** Google Fonts (Playfair Display, Space Grotesk, Space Mono), Three.js (CDN, guide articles), Calendly (contact page)

### No build step
Serve the folder with any static server (`python3 -m http.server`), or open files directly. No `package.json`.

## Design System: HIVE (`assets/css/hive.css`)

Black / grey honeycomb with a single red signal.

```css
--bg: #050505;  --bg-1: #0a0a0a;  --bg-2: #101010;
--line: rgba(255,255,255,.07);  --line-2: rgba(255,255,255,.14);
--text: #f3f3f1;  --soft: #cfcfcb;  --muted: #8d8d8a;  --dim: #5a5a58;
--red: #D72638;  --red-dk: #B71C2C;
--font-display: 'Playfair Display'  (headings, italic for emphasis)
--font-body: 'Space Grotesk'         (copy, weight 300)
--font-mono: 'Space Mono'            (labels, nav, tags, uppercase + tracking)
--hex: polygon(50% 0,100% 25%,100% 75%,50% 100%,0 75%,0 25%)
```

Building blocks: `.wrap` (1240px), `.sec` + `.sec-head` (index / line / name), `.sec-title`, `.btn` / `.btn-primary`, `.tag`, `.soc` (hexagon icon button), `.cell` honeycomb cells, `.tl` timeline with hex nodes, `.form` / `.field`, `.foot` with outlined wordmark.

### Motion (all in `hive.js`, each block is optional per page)
- `#hive canvas`: fixed honeycomb lattice drawn in world space (parallax 0.18). Cells brighten near the pointer, a wave passes through the lattice while scrolling, a few red cells breathe. Static single draw under `prefers-reduced-motion`.
- Reveals are **scroll-driven** (`.rv` gets `.in` when its top passes 92% of the viewport; `.rv-l/.rv-r/.rv-s` variants; `.rl > span` line masks; `.rv-0` = trigger only). No IntersectionObserver.
- Hero entrance is pure CSS (`.h-in`, `.h-rl`), so it never depends on JS. `html.fast` (set from `sessionStorage`) skips the loader on repeat visits.
- Cursor (fine pointers only), magnetic `.btn`, portrait tilt, nav `.scrolled`, progress bar, hero/footer wordmark drift, timeline fill.
- Gotcha: keep `overflow-x: hidden` on `html`, never on `body` (body becomes the scroller and `window.scrollY` stays 0).

## Key Patterns

### Contact form
`#contactForm` sends Name / Email / Message as GET params to the n8n webhook `https://n8n.srv1419396.hstgr.cloud/webhook/website-form-sendAmessage` with `mode: 'no-cors'` (success assumed). Handled in `hive.js` (homepage and contact page).

### SEO
Every page: canonical, Open Graph, Twitter card, JSON-LD (Person / BreadcrumbList / Article as relevant), the shared favicon set, author "Anshul Namdev". `sitemap.xml` lists every real page with image extensions; `robots.txt` allows everything.

## Content

- **n8n hub** (`/n8n/`): certificate verifier, ecosystem links, workflow showcase, Three.js hero.
- **n8n guide** (`/n8n/guide/`): one directory per article, academy template (`n8n.css`, `3d-anim.js`, `text-highlight-share.js`). Keep model lists current; only list models that are live on each provider.
- **Thoughts** (`/thoughts/`): opinion pieces, same template.
- **Blog**: `/blog/` page plus external `https://blog.axshul.site`. The subdomain is a separate Hostinger host with its own copy of the page and none of the repo assets, so the repo copy `/blog/index.html` uses relative paths, and the builder also writes an absolute-URL copy to `_uploads/blog.axshul.site/index.html` (git-ignored) that must be uploaded to that host by hand after changes.

## Photos

## Development Notes

- Preview: `python3 -m http.server 8890` from the repo root (the desktop app's launch config serves the same folder on 8888).
- When adding a page: copy the homepage head boilerplate, link `assets/css/hive.css` + `assets/js/hive.js`, reuse the nav block verbatim, add JSON-LD, add the URL to `sitemap.xml`.
- When adding a guide article: create `/n8n/guide/<slug>/index.html`, add it to the guide index and to `sitemap.xml`.
- Commit style: short imperative subject (e.g. `Fix hero image CDN 404`, `+ Article + sitemap updated`).
